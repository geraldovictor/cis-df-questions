Instale CIS DF para estudar offline

No primeiro acesso, mantenha a internet conectada enquanto o site salva as questões.

Como instalar no meu dispositivo

Android ou computador: no Chrome ou Edge, abra o menu e procure “Instalar aplicativo” ou “Instalar este site como aplicativo”. Se aparecer acima, use o botão “Instalar aplicativo”.

iPhone ou iPad: abra no Safari, toque em Compartilhar e depois em “Adicionar à Tela de Início”.

Depois de instalar, abra pelo ícone CIS DF. Os estudos começam sem login. Para ouvir sem internet, use “Salvar áudios para ouvir offline”.
